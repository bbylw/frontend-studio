# Copywriting

Frameworks and techniques for persuasive web copy. Use for landing pages, marketing sites, product pages, and any interface where text drives action.

---

## Core Job

1. Grab attention → 2. Create desire → 3. Remove friction → 4. Prompt action

Every piece of copy on a page should serve one of these four goals.

---

## Frameworks

### AIDA (Attention → Interest → Desire → Action)

Best for: Landing pages, emails, product announcements.

```
ATTENTION:  Bold headline (promise or pain point)
INTEREST:   Elaborate on the problem — make the reader say "yes, that's me"
DESIRE:     Show the transformation — what life looks like after the solution
ACTION:     Clear, specific CTA with no ambiguity
```

### PAS (Problem → Agitate → Solution)

Best for: Pain-driven products, SaaS, productivity tools.

```
PROBLEM:    State the problem clearly and specifically
AGITATE:    Make it urgent — what happens if they don't act?
SOLUTION:   Present your product as the answer
```

### FAB (Feature → Advantage → Benefit)

Best for: Product pages, feature comparisons, differentiation.

```
FEATURE:    What it does (the capability)
ADVANTAGE:  Why it matters (the practical impact)
BENEFIT:    What the customer gains (the emotional outcome)
```

## Headlines

The headline is the most important element on the page. If it fails, nothing else matters.

### Formulas

| Formula       | Example                                      |
| ------------- | -------------------------------------------- |
| **Promise**   | "Double open rates in 30 days"              |
| **Question**  | "Still wasting 10 hours/week on manual work?" |
| **How-To**    | "How to automate your entire pipeline"       |
| **Number**    | "7 mistakes killing your conversion rate"    |
| **Negative**  | "Stop losing leads to slow follow-ups"       |
| **Curiosity** | "The one change that tripled our bookings"   |
| **Transform** | "From 50 to 500 leads — here's exactly how" |

### Rules

- Lead with outcome, not method
- Be specific — numbers and details outperform vague claims
- Address the reader directly ("you", "your")
- Keep under 15 words for primary headlines

## CTAs (Call to Action)

### Bad vs Good

| Bad            | Good                          |
| -------------- | ----------------------------- |
| Submit         | Start my free trial           |
| Click here     | Get the template now          |
| Learn more     | See how it works              |
| Sign up        | Book my strategy call         |
| Download       | Download the free guide       |

### Formula

**[Action Verb] + [What They Get] + [Urgency/Ease]**

- "Start my free trial" = Action + Benefit + Ease
- "Claim your spot — only 3 left" = Action + Benefit + Urgency
- "Get instant access" = Action + Benefit + Ease

### Placement

- Above the fold (primary)
- After each value proposition section
- Multiple on long pages (every 2-3 sections)
- Near social proof or testimonials

## Emotional Triggers

| Trigger        | Example                                              |
| -------------- | ---------------------------------------------------- |
| **FOMO**       | "Only 3 spots left in the cohort"                   |
| **Fear of loss** | "Every day without this, you're losing $X"         |
| **Status**     | "Join 10,000+ top agencies already using this"       |
| **Ease**       | "Set it up once. Forget forever."                    |
| **Frustration** | "Tired of tools that deliver nothing?"              |
| **Hope**       | "Yes, you CAN hit $10K MRR"                         |

Use 1-2 triggers per page section. Overuse dilutes impact.

## Objection Handling

Address objections proactively — don't wait for the reader to think of them.

| Objection           | Response                                                  |
| ------------------- | --------------------------------------------------------- |
| Too expensive       | Show ROI: "Pays for itself in 2 weeks"                   |
| Won't work for me   | Social proof from similar customer                        |
| No time to learn    | "Setup takes 10 minutes"                                  |
| What if it fails    | "30-day money-back guarantee"                             |
| Need to think       | Scarcity/urgency: "Price increases Friday"                |
| Already using X     | Direct comparison: "Unlike X, we also..."                 |

**Placement**: FAQ section, near CTA, within testimonials, as comparison tables.

---

## Proof Types

Layer multiple proof types throughout the page:

1. **Testimonials** — Quotes with name, title, company. Specific > vague.
2. **Case studies** — Before/after with measurable results.
3. **Data/metrics** — "3x faster", "98% uptime", "10,000+ users".
4. **Social proof** — Logos, user count, community size.
5. **Certifications** — Awards, badges, security compliance.

## Section Copy Guide

| Section          | Purpose                          | Tone                          |
| ---------------- | -------------------------------- | ----------------------------- |
| Hero headline    | Stop the scroll, state the value | Bold, direct, outcome-focused |
| Subheadline      | Clarify who it's for             | Specific, relatable           |
| Feature block    | Explain a capability             | Clear, benefit-driven         |
| Social proof     | Build trust                      | Authentic, quantified         |
| FAQ              | Remove objections                | Honest, reassuring            |
| Final CTA        | Close the deal                   | Confident, urgent             |
